# Scaleway AI API

- Documentation : https://www.scaleway.com/en/developers/api/generative-apis
- Endpoint : `https://api.scaleway.ai/<projet>/v1` (identifiant de projet Scaleway)
- Configuration (`.env` racine) :
  - `FOURNISSEUR_NOM=scaleway`,
  - `FOURNISSEUR_BASE_URL=https://api.scaleway.ai/<projet>/v1`,
  - `FOURNISSEUR_API_KEY=<clé Scaleway>`.
- `Authorization: Bearer $FOURNISSEUR_API_KEY`
