# Architecture Decision Records (ADR)

Les ADR conservent la trace des décisions architecturales structurantes.

Créer un fichier `ADR-NNNN-titre-court.md` (numéro sur 4 chiffres) par décision, à partir de
[`ADR-0000-template.md`](ADR-0000-template.md). Ne pas réécrire silencieusement une décision
acceptée : créer un nouvel ADR qui la remplace et mettre à jour son statut.
