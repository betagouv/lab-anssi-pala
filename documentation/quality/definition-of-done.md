# Definition of Done

Une modification est terminée lorsque les critères applicables sont satisfaits :

- [ ] Le besoin et le périmètre sont compris.
- [ ] L'architecture et les frontières des modules sont respectées.
- [ ] Les responsabilités sont correctement séparées.
- [ ] Les dépendances sont explicites et injectées.
- [ ] Les tests pertinents sont écrits ou adaptés.
- [ ] Tous les tests concernés passent.
- [ ] Le lint et le contrôle TypeScript passent.
- [ ] Les erreurs sont correctement gérées.
- [ ] Aucun secret ou donnée sensible n'est exposé.
- [ ] La documentation concernée est mise à jour.
- [ ] Les compromis et limites restantes sont signalés.
