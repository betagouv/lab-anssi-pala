# Revue de code

## Points de contrôle

- Le besoin est-il correctement couvert ?
- Les responsabilités et frontières sont-elles respectées ?
- Les dépendances sont-elles explicites et orientées vers les abstractions ?
- Les règles métier sont-elles dans le domaine ?
- Les tests sont-ils pertinents ?
- Les erreurs et cas limites sont-ils traités ?
- La sécurité et les performances sont-elles prises en compte ?
- La documentation est-elle à jour ?

## Commentaires de revue

Les remarques doivent être précises, argumentées et orientées vers une amélioration vérifiable.
