# Usage de la langue française

## 1. Objectif

Faire du français la langue de référence du projet.

## 2. Règles obligatoires

- Répondre en français.
- Rédiger la documentation et les commentaires en français.
- Utiliser le français pour les concepts métier.
- Utiliser le français pour les classes, méthodes et propriétés métier lorsque cela est cohérent avec les conventions techniques.
- Rédiger les messages destinés aux utilisateurs en français.
- Respecter le glossaire métier.

## 3. Exceptions

Peuvent rester en anglais :

- mots-clés du langage ;
- API et conventions imposées par les frameworks ;
- noms de bibliothèques et dépendances ;
- termes techniques universels ;
- noms imposés par les contrats externes ;
- fichiers et clés de configuration soumis à une convention technique.

## 4. Cohérence

Ne pas mélanger les langues pour un même concept métier. Employer le même terme dans le domaine, l'application, la présentation et la documentation.

## 5. Critères de validation

Les noms métier, commentaires, messages et documents respectent une convention linguistique homogène.
