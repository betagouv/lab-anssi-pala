# Tests frontend

## Règles

- Tester les comportements observables par l'utilisateur.
- Vérifier les interactions, états de chargement, erreurs et cas vides pertinents.
- Éviter de coupler les tests à la structure interne du composant.
- Utiliser les outils déjà présents dans le projet.
- Tester l'accessibilité et les interactions clavier lorsque pertinent.
- Ne pas remplacer les tests de composants par des tests d'implémentation.

## Méthode

1. Identifier les scénarios utilisateurs.
2. Préparer les dépendances et données de test.
3. Vérifier le rendu et les interactions.
4. Vérifier les états d'erreur et limites.
5. Exécuter la suite frontend.
