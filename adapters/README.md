# Adaptateurs d'agents

Le référentiel canonique est `AGENTS.md`, `docs/` et `../.agents/skills`. Les adaptateurs ne doivent contenir que ce qui est nécessaire pour rendre ces instructions découvrables et utilisables par un agent donné.

## Principes

- Ne pas dupliquer les règles métier ou architecturales.
- Référencer les fichiers canoniques.
- Documenter les limites de découverte automatique.
- Vérifier les formats et mécanismes officiellement pris en charge par chaque agent avant de les configurer.
- Garder les adaptations minimales et révisables.
